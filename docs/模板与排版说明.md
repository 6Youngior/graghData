# 复旦 Beamer 模板与排版说明

## 可核验的模板来源

本报告采用 [sonnyhcl/beamerthemefdu](https://github.com/sonnyhcl/beamerthemefdu)，一个公开的复旦大学非官方 Beamer 主题。使用前核对了仓库 README、原始 example.pdf、主题源码和 Apache-2.0 许可证；不将它描述为学校官方统一发布的模板。

原始文件位于 docs/slides/vendor-fdu/，原始校徽/校名矢量资源位于 docs/slides/resources/。模板文件的 Git blob SHA 为 **9f6115ae955c02b47d26df5bff00a2a9c687bbb1**。下载地址和 SHA-256 记录在 data/source_manifest.json，完整 Apache-2.0 许可随附。

## 保留哪些原生结构

report.tex 使用 `\usetheme{fdu}` 和原生 `\titlepage`。保留主题定义的：

- 蓝色章节导航及标题栏；
- 每页右下区域的复旦校徽矢量水印；
- 分别显示小组、短标题和页码的三段页脚，作者栏为“第十三组”；
- 封面的复旦校名标识和主题标题框；
- 方形列表符号、主题块和统一章节样式。

正文通过 section 组织为“背景与问题 / 论文方法 / 改进方法 / 实验结果 / 总结”，备用部分为“问答附录”。封面不列报告时长。正文和封面使用同一个主题。

## 为中文与宽屏做的配置

原始 .sty 不改动；配置写在 report.tex 中：

- 微软雅黑、Arial 以及独立数学字体，保证中文与公式可读；
- 设置与校徽协调的蓝色及辅助色，保留原生标题、导航、页脚模板；
- 封面沿用原生校名图尺寸和标题页结构；
- 将原生水印透明度从 0.05 调为 0.022，保留校徽形状，同时减轻对算法图与表格的干扰；
- 删除无关的交互导航图标；校内章节跳转保持白色，避免蓝色链接在深底页脚上难辨；
- 统一正文与图表字号，移除页底小号注释，逐页核对边界与留白；论文信息集中列在论文介绍和参考文献页。

水印透明度及页脚作者元信息使用宏补丁配置，保留模板的背景、标题、导航和三段页脚结构。补丁失败时编译会报错。页脚只显示组号，不附加学校名称。

## 核验

code/scripts/check_theme.py 核对上游主题文件 Git blob、原生模板调用、各页组号与共同校徽水印对象，并检查封面文字。编译和文字边界检查见 data/results/pdf_build_check.json、pdf_visual_audit.json。正文算法和实验页的预览在 data/results/preview/slides/，本地可逐页查看。
