# 教师要求与报告结构

依据 docs/course/期中汇报.pptx 第 4–5 页：针对图算法任务阅读并汇报一篇或多篇论文，讲清动机与问题、思路与框架、技术、创新点，并可讨论自己的方案。原始要求文件未改动。

| 教师要求 | 正文安排 |
|---|---|
| motivation 与问题定义 | 第 2 页：社交/信任网络背景，重复查询动机，至多 k 跳的形式化定义与图例 |
| 阅读并汇报论文 | 第 3 页：K-Reach 全题名、作者、刊物年份与总体框架；第 4–7 页：核心技术、查询及算例 |
| 思路与框架 | 第 3 页：顶点覆盖→三档索引→四类查询；第 9 页：离线约简与在线选择边界 |
| 所采用技术 | 第 4–6 页：覆盖结构、阈值编码和分类；第 8–9 页：集合支配、双预算与正反向处理 |
| 创新点与自己的方案 | 第 8 页提出边界约简，第 9 页说明预算差异，第 13 页归纳改进及见证替代依据 |
| 实验与结果 | 第 10–12 页：对照、消融、查找数、时间和开销 |
| 相关研究 | 论文精读、文献调研及附录 J；K-Reach 2012、VCRea 2023、CSUR 在线 2025 / 卷期 2026 |
| 汇报结构 | 背景与问题→论文方法→改进方法→实验结果→总结；13 页主讲，随后为问答备份 |
| 模板与呈现 | 原生复旦主题，正文沿用标题、导航、水印与页脚；作者显示为第十三组，封面不列报告时长 |

原文的覆盖、三档索引、四类查询、求交和压缩均归功于作者。课程方案在该框架中利用阈值支配约简边界，给出预算反例、正确性证明和验证。文献引用、本机结果与合成实验分别标示。
